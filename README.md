INVICTTA-Remembering the Forgotten

About the Project:

This project is dedicated to RANI GAIDINILU, a young freedom fighter from Northwest India whose 
story deserves to be remembered.

WHY I MADE THIS??

While learning about India's freedom struggle, I realized that there are many people
whose stories are talked about enough.
This project is a small attempt to bring one of those stories to screen
